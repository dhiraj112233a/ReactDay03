⭐ What is React :
- React is a JavaScript library for building user interfaces (UIs), especially for web applications.
- It is developed by Meta for building user interfaces using reusable components.

⭐ Advantages of React :
- It is Easy to Learn
- React applications are made of components which are Reusable.

⭐ Props in React :
- Props (properties) are used to send data from a parent component to a child component in React.

⭐ What is a State In React : 
- In React, State is a built-in JavaScript object used to contain data or information about the component. 
- State is used to store and update dynamic data in a React component.

⭐ What is a Component In React :
- A component is a reusable building block used to create the user interface in React.
- Eg. A website can be divided into components like:
*Header
*Navbar
*Content
*Footer

⭐ What is a Virtual DOM In React :
- The Real DOM (Document Object Model) is the actual structure of a web page that the browser creates from HTML.
- When data changes, the browser may need to update the DOM, which can be slower if many elements are involved.

⭐ What is a Real DOM In React :
- The Real DOM is the actual DOM created by the browser. Updating it frequently can be slower because the browser has to process those changes.

⭐ Does React use OOPS?
- React is not an OOP framework. It is a component-based JavaScript library. Although JavaScript supports OOP concepts like encapsulation, inheritance, polymorphism, and abstraction, modern React mainly uses components, props, state, and composition rather than inheritance.
