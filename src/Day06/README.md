⭐ What is Axios?
- Axios is a JavaScript library used to communicate with APIs.
- In React , Axios is commonlu use to get, send, update, and delete data from a backend/server.
- Axios Methods : 
    axios.get()       → Get data
    axios.post()      → Send/Create data
    axios.put()       → Update data
    axios.delete()    → Delete data
- In short Axios is a tool/library that helps React communicate with APIs easily.
